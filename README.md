# Who Is Imposter?

Tek telefonla yüz yüze oynanan mobil parti oyunu. İnternet gerekmez.

## Kurulum

```bash
npm install
```

## Geliştirme

```bash
npm run dev
```

Tarayıcıda `http://localhost:5173` adresine gidin.

## Production Build

```bash
npm run build
```

Çıktı `dist/` klasöründe oluşur. Herhangi bir statik sunucuyla servis edilebilir:

```bash
npm run preview
```
